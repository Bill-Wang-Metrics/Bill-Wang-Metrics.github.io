# Bill Wang's academic website

This repository contains the source for [bill-wang-metrics.github.io](https://bill-wang-metrics.github.io), built with the [Academic Pages](https://github.com/academicpages/academicpages.github.io) Jekyll template.

## Updating the site

- Edit `_pages/about.md` for the home-page biography.
- Add publications as Markdown files in `_publications/`.
- Edit `_pages/cv.md`, or place a PDF in `files/` and link to it.
- Add a square profile photo as `images/profile.png`.
- Edit `_config.yml` for contact details, affiliation, and academic profile links.

Changes pushed to `main` are deployed automatically with GitHub Actions.
